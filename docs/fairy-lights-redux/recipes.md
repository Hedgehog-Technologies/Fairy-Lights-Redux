# Fairy Lights Redux recipes

Every crafting recipe in the mod, as it's currently ported. Update this file whenever a recipe is
added or changed.

Shaped recipes are generated by FLRecipeProvider (run `./gradlew :neoforge:runData`) and show in the
recipe book. Everything that comes in colors uses DyedShapedRecipe
(`fairylightsredux:crafting_dyed_shaped`): a shaped recipe whose D slot takes any dye (`c:dyes`),
with the result taking that dye's color, so there's one recipe per item rather than one per color.
In the recipe book its result shows as white. Special recipes are CustomRecipe classes in
server/item/crafting. Their JSON only names the serializer, so they don't show in the recipe book.
JEI shows examples of them (on NeoForge only), but the rules below are the full reference.

Item tags used below (data/fairylightsredux/tags/item):

- lights: every light.
- dyeable_lights: the 15 simple lights, icicle lights and meteor light.
- twinkling_lights: the 15 simple lights and icicle lights.
- pennants: the four pennants.
- dyeable: dyeable_lights, pennants and tinsel.

Common ingredients are conventional `c:` tags, so modded equivalents work, the same as the old
mod's Forge tags:

| Ingredient     | Tag                                                                                                  |
|----------------|------------------------------------------------------------------------------------------------------|
| Iron ingot     | `c:ingots/iron`                                                                                      |
| String         | `c:strings`                                                                                          |
| Dye            | `c:dyes`; its color comes from the item if it's a vanilla-style dye, otherwise from `c:dyes/<color>` |
| White dye      | anything whose dye color is white, as above                                                          |
| Glowstone dust | `c:dusts/glowstone`                                                                                  |
| Gold nugget    | `c:nuggets/gold`                                                                                     |
| Bone           | `c:bones`                                                                                            |
| Feather        | `c:feathers`                                                                                         |
| Glass pane     | `c:glass_panes/colorless`                                                                            |

White and red stained glass panes are the vanilla items: no loader has a tag for one color of
pane. Forge 1.21.8 keeps bones and feathers under `forge:`, so the mod adds `c:bones` and
`c:feathers` on Forge, pointing at them.

## Lights

### Dyed lights

Every dyeable light shares the same frame: iron ingot on top, a dye in the center. The dye sets
the light's color. Each light has one recipe, and it makes 4.

```
 I        I = iron ingot
?D?       D = any dye
???       ? = per light, see below
```

### Redyeing lights

Eight lights of the same kind around a dye makes 8 of that light in the dye's color. There's one
per light, in the same recipe book group as the light's crafting recipe.

```
LLL       L = the light (any color)
LDL       D = any dye
LLL
```

Recipe ids: `<light>_redye`.

## Hanging lights

### Hanging lights (`hanging_lights`, special)

Makes one hanging lights item.

- Needs iron ingot, string, iron ingot side by side in a row.
- Needs at least one item from the lights tag anywhere else in the grid. The lights become the
  string's pattern, in grid order (left to right, top to bottom), one light per stack.
- Optional: one white dye anywhere for white string. Without it the string is black.
- Optional: one glowstone dust anywhere to make every light in the pattern that can twinkle (the
  twinkling_lights tag) twinkle. It doesn't match if none of the lights can twinkle.
- Nothing else may be in the grid.

### Changing the pattern or string (`hanging_lights_augmentation`, special)

Hanging lights plus, in any slots, one or more items from the lights tag, a white dye, or both.
Makes one.

- New lights replace the whole pattern in grid order. Without any, the pattern is kept.
- A white dye makes the string white. Without one, the string color is kept.
- A white dye on its own doesn't match if the string is already white.

## Pennant bunting

### Pennant bunting (`pennant_bunting`, special)

Works like hanging lights. Iron ingot, string, iron ingot side by side in a row, plus at least one
item from the pennants tag anywhere else. The pennants become the pattern in grid order. Nothing
else may be in the grid. Makes one.

### Changing the pennant pattern (`pennant_bunting_augmentation`, special)

Pennant bunting plus one or more pennants, in any slots. The new pennants replace the whole
pattern in grid order. Makes one.

## Letter bunting

```
I-I       I = iron ingot, - = string
PBF       P = paper, B = ink sac, F = feather
```

Makes one letter bunting with no text. Placing it opens the text editor, and sneak-using it (or
pennant bunting) later opens it again.

## Pennants

Each pennant has one recipe, and it makes 1. The dye sets its color.

```
- -       - = string
PDP       P = paper, D = any dye
???       ? = per pennant, see below
```

| Pennant             | Bottom row |
|---------------------|------------|
| Triangle pennant    | ` P `      |
| Spearhead pennant   | ` PP`      |
| Swallowtail pennant | `P P`      |
| Square pennant      | `PPP`      |

Recipe ids: `<pennant>`, for example `square_pennant`.

## Garlands

### Tinsel garland

One recipe, making 1 tinsel in the dye's color.

```
 P        P = paper
I-I       I = iron ingot, - = string
 D        D = any dye
```

Recipe id: `tinsel`.

### Vine garland

Iron ingot, vine, iron ingot in a row (`I-I`). Makes 2.

## Light modifiers

### Twinkling (`light_twinkle`, special)

One item from the twinkling_lights tag plus one glowstone dust, in any slots. Makes one light that
twinkles. The light keeps its color and any other modifiers.

### Color changing (`color_changing_light`, special)

- One item from the dyeable_lights tag with a gold nugget directly to its left or right.
- One or more dyes anywhere else.
- Nothing else may be in the grid.

Makes one light that fades through a list of colors. The light's current color comes first, then
each dye in grid order. Doing it again on a color-changing light replaces its color list with the
new dyes.

## Color editing

### Dyeing (`edit_color`, special)

One item from the dyeable tag plus one or more dyes, in any slots. The dyes are blended into one
color, which replaces the item's color. Makes one.

On a color-changing light this sets the underlying color but the light keeps changing color,
the same as in the old mod.

### Copying a color (`copy_color`, special)

Exactly two items from the dyeable tag, in any slots. The second item (in grid order) takes the
first item's color. Makes one, and the first item is handed back. Only the single color is
copied, not a color-changing list.

## Not ported yet

Nothing: every crafting recipe from the old mod is ported.
